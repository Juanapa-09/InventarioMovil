Versión de prueba: los datos se guardan en esta computadora o celular, dentro de este navegador. No se sincronizan entre dispositivos. Exporta copias de seguridad con frecuencia. Las bibliotecas de códigos de barras, escáner y Excel necesitan internet.

3. Códigos de barras para imprimir

Se genera una etiqueta por producto registrado. Imprime en papel adhesivo o papel normal y pega la etiqueta de forma segura y legible.

4. Respaldo y exportación

Descarga los datos para conservar una copia o revisarlos en Excel. El archivo Excel contiene hojas de productos y conteo físico.

No importes archivos que no reconozcas: pueden sobrescribir tus productos y conteos actuales.
