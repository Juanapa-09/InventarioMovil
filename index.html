Control de productos, conteo físico y códigos de barras

Versión de prueba: los datos se guardan en este navegador. Para que varios trabajadores compartan información en tiempo real se necesita conectar un servicio de base de datos en la nube. Exporta copias de seguridad con frecuencia. Las bibliotecas de códigos de barras, escáner y Excel necesitan internet.

1. Catálogo de productos

Importar / actualizar catálogo desde Excel

Carga el Excel de productos cada vez que recibas una versión nueva. Se actualizarán los nombres y saldos de los SKU existentes y se agregarán los nuevos, sin borrar los conteos.

Columnas reconocidas: CODIGO / SKU / COD, DESCRIPCION / PRODUCTO / NOMBRE y SALDO / STOCK. Los códigos duplicados con descripciones diferentes se informarán para revisión.

El SKU será el valor del código de barras. Usa un código distinto para cada producto.

3. Códigos de barras para imprimir

Se genera una etiqueta por producto registrado. Imprime en papel adhesivo o papel normal y pega la etiqueta de forma segura y legible.

4. Respaldo y exportación

Descarga los productos, el conteo actual y el historial detallado por área, responsable y fecha. El saldo del Excel maestro se conserva como referencia.

Uso por varios trabajadores: esta versión registra el nombre del responsable, pero todavía guarda datos localmente en cada dispositivo. La sincronización compartida requiere configurar una base de datos central con usuarios y permisos; no se activa solo por publicar el HTML.

No importes archivos que no reconozcas: pueden sobrescribir tus productos y conteos actuales.
